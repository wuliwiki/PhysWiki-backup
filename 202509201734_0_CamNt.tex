手机一倍相机视角一般是 60° 左右。

例如 Samsung s ultra 24 的水平视角为 73.7°（$2\tan^{-1}(3/4)$）。

\begin{itemize}
\item 全画幅是 36×24（单位 mm，下同）
\item 索尼半画幅（APS-C）： 传感器尺寸 ≈ 23.6×15.7 （面积为全画幅的 42.8\%）
\item 佳能： 半画幅 约 22.3×14.9
\item M4/3画幅： 传感器尺寸 = 17.3×13（面积为全画幅的 26\%）
\end{itemize}
