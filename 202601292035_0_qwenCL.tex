\begin{itemize}
\item \href{https://help.aliyun.com/zh/model-studio/qwen-code#bfe3dff25ecxb}{下载安装 CLI，初步使用} 其中 ubuntu22 装 npm 的命令见 \enref{Node.JS 笔记}{NodeJS}。
\item \verb`/help` 可以看到帮助，有用的如下
\item \verb`/auth` 可以切换账号和 api key
\item \verb`@ to specify files for context`
\item \verb`Execute shell commands via ! (e.g., !npm run start)`
\item \verb`/init - Analyzes the project and creates a tailored QWEN.md file`
\item \verb`/stats model` 查看本次启动 Qwen Code 后的 Token 消耗与 API 调用次数。
\end{itemize}
